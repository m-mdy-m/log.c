# Code of Conduct

## Our pledge

We want participation in `m-mdy-m/log.c` to be welcoming, respectful, and focused on improving the project. Everyone should be able to contribute without harassment or discrimination.

## Expected behavior

- Be respectful and considerate, including when you disagree.
- Explain technical feedback clearly and discuss code or ideas, not the person.
- Accept constructive criticism and keep discussions relevant to the project.
- Respect other people's privacy. Do not publish private information without permission.

## Unacceptable behavior

Harassment, insults, threats, discriminatory language, deliberate intimidation, unwanted sexual attention, publishing private information, and sustained disruptive behavior are not acceptable.

## Scope

This code applies to project spaces, including issues, pull requests, code reviews, and other communications conducted on behalf of the project.

## Reporting and enforcement

Report conduct concerns privately to the project maintainer using the private contact method listed on the maintainer's GitHub profile. Do not post sensitive details in a public issue. Reports will be reviewed as fairly and confidentially as practical. Depending on the situation, the maintainer may edit or remove content, ask someone to stop, close a discussion, or restrict participation.

This project is maintained on a best-effort basis. Reports will be handled respectfully, but a response time cannot be guaranteed.
